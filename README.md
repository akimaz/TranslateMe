# Project 6 - TranslateMe

Submitted by: **Angelina Kimaz**

**TranslateMe** is an iOS app that allows users to translate English words, phrases, and sentences into Spanish. The app uses the MyMemory Translation API and Firebase Firestore to save and manage translation history.

Time spent: 6 hours spent in total

## Required Features

The following **required** functionality is completed:

- [x] Users open the app to a TranslateMe home page with a place to enter a word, phrase, or sentence, a button to translate, and another field that is initially empty.
- [x] When users tap translate, the English text translates into Spanish in the lower field.
- [x] A history of translations can be stored and viewed on a separate screen.
- [x] The history of translations can be erased.

The following **optional** features are implemented:

- [ ] Add a variety of choices for the languages.
- [x] Add UI flair.

The following **additional** features are implemented:

- [x] Integrated Firebase Firestore to save translations.
- [x] Added a separate screen to view saved translations.
- [x] Added the ability to delete individual translations.
- [x] Added a button to clear all saved translations.
- [x] Used the MyMemory Translation API for English-to-Spanish translation.
